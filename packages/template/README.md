# `@lilium/template`

Target-independent immutable template declarations and component composition for Lilium.

Status: **First public ABI complete**

Template depends on `@lilium/core` and `@lilium/component`. It defines declarative template programs, bindings, component composition, slots, and projections without depending on renderers, DOM APIs, or compiler syntax.
